# 작업 요청과 인계

## 앤 → 역할
- 책임 역할 / 작업:
- system_root (절대 경로):
- project_root (절대 경로):
- product_record (절대 경로):
- 입력 파일·원문·근거 ID:
- 기준 결정·산출물 버전:
- 포함 범위 / 제외 범위:
- 수정 가능한 경로 / 읽기 전용 경로:
- 기존 사용자 권한과 제한:
- 완료 조건과 필요한 검증:
- 독립 작업과 의존 작업:

## 역할 → 앤
- 사용한 기준 버전:
- 완료한 것:
- 실제 결과물·버전:
- 실제 수행한 검사·환경·결과·증거:
- 미검증·한계·남은 문제:
- 이전 의도·화면과 달라진 부분:
- 필요한 결정(없으면 없음):
- 다음 행동·책임 역할:
- 공통 기록에 반영할 사항:

아크가 검토하는 경우 기준별 ready / revise / unverified / needs-decision과 근거·영향·담당을 함께 반환한다. 수행하지 않은 역할 호출·조사·검증을 기록하지 않는다.
